# O'Ryan Event Ledger (web build)

Static build of the O'Ryan Event Center booking ledger, served at https://ledger.oryaneventcenter.com.

This repository contains only the generated front end. Records live in a private Google Sheet; every call requires Google sign-in, an allowlisted account, and editor access to that Sheet. Source and build scripts live in the private project repository (`scripts/build-web.mjs`).
